# zsh-vibecheck

Three zsh functions for your `.zshrc` that you absolutely need.

- `based` — prints a gigachad and a certified BASED verdict
- `cringe` — prints a soyjak and a brutal CRINGE verdict  
- `vibecheck` — coin flip. you don't get to choose.

## Install

### Manual
```zsh
git clone https://github.com/Amir0234-afk/zsh-vibecheck ~/.config/zsh/vibecheck
```

Add to `.zshrc`:
```zsh
source ~/.config/zsh/vibecheck/vibecheck.zsh
```

### oh-my-zsh
```zsh
git clone https://github.com/Amir0234-afk/zsh-vibecheck ${ZSH_CUSTOM:-~/.oh-my-zsh/custom}/plugins/vibecheck
```
Add `vibecheck` to your plugins list in `.zshrc`.

## Dependencies
- `pv` — `sudo apt install pv`
